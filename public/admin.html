Reconocimiento

Lectura con IA

Con la IA activada, cada documento subido lo lee Claude (de Anthropic): entiende cualquier maquetación, fotos torcidas o con poca luz y letra pequeña. El resultado pasa por las mismas comprobaciones (NIF, IBAN, cuadre de importes) y se combina con la lectura local. Si la IA no responde, se usa la lectura local automáticamente.

1

2
Añade saldo en Billing

3
API Keys → Create Key

Copia la clave (empieza por sk-ant-) y pégala aquí

Los documentos se envían a la API de Anthropic solo para leerlos. La clave se guarda en la base de datos local de Gesty (data/gesty.db).
